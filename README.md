# 🚀 Node.js Проект для Новичков + Гайд по Vibe Code

Этот проект создан специально для новичков в разработке, чтобы проверить работу Node.js и npm, а также научиться эффективно работать с Vibe Code (ИИ-помощником для разработки).

## 📋 Что это за проект?

Простой тестовый проект, который:
- ✅ Проверяет установку Node.js
- ✅ Показывает базовые возможности JavaScript
- ✅ Демонстрирует работу npm скриптов
- ✅ Учит работать с Vibe Code

## 🛠️ Установка и запуск

### Шаг 1: Проверка установки Node.js

Откройте терминал и выполните:

```bash
node --version
npm --version
```

Если видите версии (например, `v18.0.0` и `9.0.0`) — всё готово! 🎉

Если команды не найдены, установите Node.js с [официального сайта](https://nodejs.org/).

### Шаг 2: Запуск проекта

```bash
# Запустить главный файл
npm start

# Или напрямую через node
node index.js

# Запустить калькулятор
npm test
```

## 🤖 ГАЙД: Как эффективно работать с Vibe Code

### Что такое Vibe Code?

**Vibe Code** — это ИИ-помощник, который помогает писать, рефакторить и понимать код. Думайте о нём как о супер-умном напарнике, который:
- Пишет код по вашему описанию
- Исправляет ошибки
- Объясняет сложные вещи простым языком
- Помогает с документацией

---

## 💡 Принципы эффективной работы с ИИ

### 1. **Формулируйте чёткие промпты**

#### ❌ Плохо:
```
"Сделай что-то с этим файлом"
"Исправь код"
"Добавь функцию"
```

#### ✅ Хорошо:
```
"Добавь в index.js функцию, которая принимает массив чисел
и возвращает только чётные числа"

"Создай в папке utils новый файл stringHelper.js с функциями:
- capitalize() - делает первую букву заглавной
- reverse() - переворачивает строку
- countWords() - считает количество слов"

"Рефактор функции greet() в index.js: добавь проверку типа
параметра и выброс ошибки, если передан не string"
```

### 2. **Просите документировать изменения**

#### ✅ Примеры хороших промптов:

```
"После каждого изменения обновляй README.md с описанием
новых функций"

"Веди лог изменений в файле CHANGELOG.md"

"Создай комментарии к каждой новой функции с примерами
использования"
```

### 3. **Разбивайте большие задачи на маленькие**

#### ❌ Плохо:
```
"Создай полноценное приложение для управления задачами
с базой данных и API"
```

#### ✅ Хорошо:
```
Шаг 1: "Создай базовую структуру проекта с папками
models, routes, controllers"

Шаг 2: "Добавь модель Task с полями: id, title,
description, completed, createdAt"

Шаг 3: "Создай функции для работы с задачами:
createTask, getTasks, updateTask, deleteTask"

...и так далее
```

## 💬 Типичные ошибки при работе с ИИ

### ❌ Ошибка 1: Слишком расплывчатые запросы
```
"Улучши код"
→ Что конкретно улучшить? Производительность? Читаемость? Безопасность?
```

### ❌ Ошибка 2: Не указывать контекст
```
"Добавь валидацию"
→ Валидацию чего? Где? Какие правила?
```

### ❌ Ошибка 3: Слишком большой скоп
```
"Сделай полное приложение"
→ Разбей на маленькие задачи!
```

### ❌ Ошибка 4: Не просить документацию
```
Код написан, но непонятно что он делает
→ Всегда просите комментарии и обновление README
```

## 🌟 Секретные советы

1. **Итеративный подход**: Не бойтесь уточнять и переделывать. "Теперь сделай это, но с обработкой ошибок"

2. **Просите варианты**: "Покажи 3 разных способа реализации этой функции"

3. **Учитесь на примерах**: "Создай функцию для работы с API и объясни каждую строку"

4. **Контекст важен**: "Я новичок, объясни как будто мне 5 лет" или "Я знаю Python, покажи аналогии с JS"

5. **Документируйте всё**: "После каждого изменения добавляй запись в CHANGELOG.md с датой и описанием"
