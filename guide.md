# Гайд ММ Вайбкод для предпринимателей

**Комплект инструкций по настройке базовой среды разработки** (версия 8.0)

Все части этого гайда можно выполнить в Cursor, Claude Code или Codex простыми запросами или отправив ссылку на этот гайд.

Гайд — более надёжный путь установки; раз работа с ИИ — суть этого ММ, имеет смысл использовать его сразу.

---

## Для кого эта инструкция

Инструкция для нетехнических пользователей, которые начинают создавать приложения с помощью AI-инструментов (Claude Code, Cursor и т.п.).

Успешное выполнение шагов уберёт главную преграду — настройку локального окружения — и позволит сразу перейти к работе с кодом, который генерирует ИИ.

---

## Четыре ключевых инструмента

| Инструмент | Зачем нужен |
|------------|-------------|
| **Git** | Система контроля версий: клонирование проектов и отслеживание изменений. |
| **Python и pip** | Язык и менеджер пакетов: AI-скрипты, бэкенд; в простой разработке часто боты, в сложной — широкое применение, особенно LLM и аналитика. |
| **Node.js и npm** | Среда JavaScript и пакеты — для большинства современных веб-приложений (фронтенд). |
| **Cursor** | AI-редактор кода — основной инструмент работы. |

## Важные правила перед началом (обязательно прочитать)

Дальше вы будете ставить другие инструменты и фреймворки — придерживайтесь простых правил.

### Выбор версии

Если при загрузке предлагают **LTS / Stable** и **Current / Latest** — выбирайте **LTS** или **Stable**: они надёжнее и проверены дольше.

### Ошибки

Если на любом этапе появляются ошибки (особенно красные в Терминале или Командной строке) или установщик падает — не паникуйте. Сделайте скриншот и сразу обратитесь к куратору или ментору.

## 1. Инструкция для macOS

### Шаг 1. Установка Homebrew (менеджер пакетов)

Homebrew — популярный способ ставить инструменты разработчика на macOS; через него удобно поставить Git.

1. Откройте **Терминал**: **⌘ + Пробел** (Spotlight) → введите «Терминал».
2. Установите Homebrew — скопируйте команду ниже, вставьте в Терминал и нажмите **Enter**:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

- Система может запросить пароль администратора — это нормально.  
- **Важно:** при вводе пароля символы **не отображаются** — так и должно быть.
- Следуйте подсказкам на экране. Если Homebrew предложит установить **Xcode Command Line Tools** — согласитесь.

#### Настройка PATH (критично)

После установки Homebrew в выводе часто есть **две команды**, которые нужно выполнить, чтобы система находила программы из Homebrew. Внимательно прочитайте вывод и выполните предложенные команды (часто это что-то вроде `echo '...' >> ...` и `eval '...'`).

**Успех:** сообщения вроде `Installation successful!` или `Homebrew is ready to brew.`

---

### Шаг 2. Установка и настройка Git

Git нужен, чтобы отслеживать изменения в коде и работать с репозиториями на GitHub и аналогах.

**Установка через Homebrew:**

```bash
brew install git
```

**Проверка:**

```bash
git --version
```

**Успех:** видите номер версии, например `git version 2.43.0`.

**Регистрация на GitHub:** [https://github.com/join](https://github.com/join)

**Настройка имени и email** (лучше совпадать с данными на GitHub):

```bash
git config --global user.name "Ваше Имя"
git config --global user.email "your.email@example.com"
```

**Успех:** после команд нет сообщений об ошибках.

---

### Шаг 3. Установка Python и pip

**Простыми словами**

- **Python** — основной язык, на котором часто пишут инструкции для компьютера; многие AI-инструменты ориентируются на Python.
- **pip** — менеджер пакетов: скачивает и устанавливает библиотеки для Python.

**Загрузка**

1. Сайт: [https://www.python.org/downloads/macos/](https://www.python.org/downloads/macos/)
2. Скачайте установщик для macOS и запустите `.pkg`, настройки по умолчанию обычно подходят.

**Проверка** (при необходимости перезапустите Терминал):

```bash
python3 --version
pip3 --version
```

**Успех:** для обеих команд видны номера версий (например, Python 3.12.x и pip 23.x).

---

### Шаг 4. Установка Node.js и npm

**Простыми словами**

- **Node.js** — позволяет запускать JavaScript вне браузера (бэкенд, инструменты).
- **npm** — менеджер пакетов для JavaScript (аналог pip для JS).

**Загрузка**

1. [https://nodejs.org/en/download](https://nodejs.org/en/download)
2. Скачайте вариант **LTS** (Long-Term Support).

Запустите `.pkg`, следуйте мастеру, настройки по умолчанию обычно ок.

**Проверка:**

```bash
node --version
npm --version
```

**Успех:** видны версии (например, `v20.x` и `10.x`).

---

### Шаг 5. Установка Cursor

Cursor — редактор с упором на AI: чат, правки кода, подсказки.

1. Сайт: [https://cursor.com/](https://cursor.com/) (ранее cursor.sh)
2. **Download for Mac**, установите из `.dmg`: перетащите Cursor в **Программы**.

**Первый запуск**

- **File → Open Folder** — выберите папку проектов; от неё зависит контекст для AI.
- **Чат с AI:** **⌘ + K** — вопросы и генерация кода.
- Выделите фрагмент кода и **⌘ + K**, чтобы попросить дописать или изменить код.

---

### Шаг 6. Клонирование пробного проекта

Когда инструменты установлены, можно скачать реальный репозиторий с GitHub и открыть его в Cursor.

#### Пароль GitHub для HTTPS

Для `git clone` по HTTPS нужен пароль аккаунта GitHub.

- Регистрация с email и паролем — пароль уже есть.
- Вход через Google, Apple и т.д. — задайте пароль: [https://github.com/settings/password](https://github.com/settings/password) → **Change password**.

#### Клонирование

1. Репозиторий: [https://github.com/Dev1love/vibecode_base_project](https://github.com/Dev1love/vibecode_base_project)
2. Зелёная кнопка **Code** → вкладка **HTTPS** → скопируйте URL.
3. В Cursor откройте встроенный терминал: **Ctrl + `** (Control + обратная кавычка) или меню **Terminal → New Terminal**.

В терминале:

```bash
git clone https://github.com/Dev1love/vibecode_base_project.git
```

Введите **username** GitHub и **пароль** при запросе.

**Успех:** строки вроде `Cloning into 'vibecode_base_project'...` и в конце `done.`

4. **File → Open Folder** — откройте папку `vibecode_base_project`.
5. Прочитайте **README.md** в корне проекта.
6. При наличии откройте **GLOSSARY.md** или `docs/glossary.md`.
7. Выполните шаги из README (например, `npm install`). Если застряли — спросите AI в Cursor (**⌘ + K**).

**Поздравляем:** среда на macOS готова, вы сделали первый шаг к разработке с AI.

## 2. Инструкция для Windows

### Шаг 1. Установка Git

1. Сайт: [https://git-scm.com/download/win](https://git-scm.com/download/win) — загрузка начнётся автоматически.
2. Запустите `.exe`, на большинстве экранов можно **Next** с настройками по умолчанию.
3. На экране **Adjusting your PATH** выберите: **Git from the command line and also from 3rd-party software**.

**Проверка** (Командная строка или PowerShell: **Win + R** → `cmd` → Enter):

```bash
git --version
```

**Успех:** версия Git, например `git version 2.43.0.windows.1`.

**GitHub:** [https://github.com/join](https://github.com/join)

**Настройка пользователя** (имя и email как на GitHub):

```bash
git config --global user.name "Ваше Имя"
git config --global user.email "your.email@example.com"
```

---

### Шаг 2. Установка Python и pip

Смысл Python и pip — тот же, что в разделе для macOS.

1. [https://www.python.org/downloads/windows/](https://www.python.org/downloads/windows/) — скачайте установщик.
2. Запустите `.exe`.  
   **Обязательно** отметьте **Add python.exe to PATH**, затем **Install Now**.

**Проверка:**

```bash
python --version
pip --version
```

(Иногда нужна команда `py --version` — смотрите подсказки установщика.)

---

### Шаг 3. Установка Node.js и npm

1. [https://nodejs.org/en/download](https://nodejs.org/en/download) — версия **LTS**.
2. Установите `.msi`, на шагах обычно достаточно **Next**; PATH настраивается автоматически.

**Проверка:**

```bash
node --version
npm --version
```

---

### Шаг 4. Установка Cursor

1. [https://cursor.com/](https://cursor.com/) — **Download for Windows**.
2. Установите по мастеру.

**Первый запуск:** **Open Folder**, чат **Ctrl + K** (в отличие от macOS).

---

### Шаг 5. Клонирование пробного проекта

Пароль для HTTPS — как в macOS-разделе: [https://github.com/settings/password](https://github.com/settings/password)

Репозиторий: [https://github.com/Dev1love/vibecode_base_project](https://github.com/Dev1love/vibecode_base_project)

В терминале Cursor (**Ctrl + `**):

```bash
git clone https://github.com/Dev1love/vibecode_base_project.git
```

При запросе логина и пароля: **пароль при вводе может не отображаться** — это нормально.

Дальше: **Open Folder** → `vibecode_base_project` → **README.md**, глоссарий при наличии, шаги из README (`npm install`, `pip install` и т.д.). Помощь — чат Cursor (**Ctrl + K**).

**Поздравляем:** среда на Windows готова.
